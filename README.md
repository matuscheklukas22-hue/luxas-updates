# LUXAS x CREMICH Updates

Update-Server fuer den LUXAS x CREMICH Client.

## Schema `latest.json`

```json
{
  "modVersion": "1.40.0-luxas2",
  "modFile": "LUXASxCREMICH-1.40.0.jar",
  "modUrl": "https://raw.githubusercontent.com/<user>/luxas-updates/main/LUXASxCREMICH-1.40.0.jar",
  "notes": "Was ist neu"
}
```

## Neue Version veroeffentlichen

1. Neue jar in diesen Ordner kopieren
2. `latest.json` aktualisieren (version, file, url, notes)
3. `UPDATE-PUSH.bat` doppelklicken

Alle Client-Nutzer kriegen beim naechsten Launcher-Start einen Banner.
